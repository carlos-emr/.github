## CARLOS EMR

**Open-source Electronic Medical Records for Canadian healthcare.**

CARLOS (Clinical Assisting Recording Ledger Open Source) is a full-featured
EMR system built for Canadian clinics. Multi-provincial billing, HL7/FHIR
interoperability, and 20+ years of heritage from the OSCAR EMR lineage --
actively maintained and modernized on Java 21 and Spring.
